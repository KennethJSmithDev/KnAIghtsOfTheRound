ABOUT THIS EXPERIENCE

A real workflow, synthetic evidence.

Each submitted case runs the native AI Hub agent through the real IRIS Interoperability production. IRIS resolves the source evidence, validates the proposal and records a fresh disposition with its audit and message identities.

The standard public configuration replays genuine recorded model completions rather than performing fresh inference. An operator can explicitly configure a live default profile; the header and each receipt identify the model response source. Only the fixed synthetic evidence cases can be submitted. This page cannot approve or execute a task. Refresh retrieves the existing receipt without submitting another review.

The chamber is an original lightweight illustration. The separately licensed 3D knight files are not included.

The default profile is configured by the operator. Where explicitly enabled, temporary-key reviews send only the selected synthetic case to the fixed Groq model after consent. An unconfirmed live response is recovered by its existing request identity; the page never switches it silently to replay. Operator-controlled approvals remain separate.
